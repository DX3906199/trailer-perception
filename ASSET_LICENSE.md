# Scene and example assets

The project owner supplies the trailer reconstruction, derived part splits,
reconstructed mesh, ground texture and synthetic example for reproducing the
demonstrations in this repository. No third-party purchased mesh, online HDRI,
raw rosbag or real camera image is distributed here.

The project's code license does not establish rights over third-party content
that might be visible in a reconstruction. For redistribution or uses beyond
reproducing this project, contact the repository owner. Asset filenames,
coordinate frames and SHA-256 values are recorded in
`assets/scene/provenance.json`.
